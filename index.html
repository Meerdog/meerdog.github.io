Shower Vibes

A generative ambient synthesizer with four tracks that create evolving soundscapes. Each track has a dancing cat that grooves when playing! 🐱

🎬 SONG MODE (Press S)

Automatically creates a 3-minute ambient journey:

  • ✨ Intro (0-18s) — Drone fades in from silence
  • 🌅 Awakening (18-45s) — Melodic bells join
  • 🌊 Rising (45-81s) — First rhythm enters
  • 🔥 Crescendo (81-117s) — Full arrangement builds to peak
  • ⭐ Peak (117-144s) — Maximum intensity plateau
  • 🌙 Fading (144-166s) — Rhythms fade out
  • 💫 Outro (166-180s) — Gentle fade to silence

The Randomness slider adds variation: bell patterns change, drift intensifies, creating unique performances each time.

🎭 SCENES

Six pre-built harmonious configurations where all tracks complement each other:

  • 🌅 Ambient Dawn — Warm major chords, gentle 72 BPM
  • 🌌 Deep Space — Haunting minor 7ths, slow 60 BPM
  • 🌲 Forest Rain — Natural minor with organic rhythms
  • 💎 Crystal Cave — Suspended chords, high resonant tones
  • 🌊 Ocean Drift — Flowing arps with long reverb tails
  • 🌙 Night Garden — Major 7ths with sidechain ducking

🎹 DRONE (Track A) — 🐱 Orange Tabby

Layered oscillators creating rich pad sounds:

  • Wave — Oscillator shape (Sine=warm, Saw=bright)
  • Chord — Harmony (Major, Minor, 7ths, Suspended)
  • Voices — Layer count (more=thicker)
  • Detune — Voice spread (adds width/chorus)
  • Drift — Slow filter/pitch movement for evolution
  • Grain — Shimmering granular texture

🔔 BELL (Track B) — 🐱 Siamese

Generative melodic arpeggiator with 11 algorithms:

  • Random — Pure chance • Drunk — Small wandering steps
  • Gravity — Pulls toward root • Bounce — Bounces off edges
  • Spiral — Expanding intervals • Breathe — Rise and fall
  • Cluster — Groups of nearby notes • Fibonacci — Math jumps
  • Weave — Low/high alternation • Echo — Phrases with variation
  • Shimmer — Octave cascades

Glide smoothly slides between notes (portamento).

🥁 DRUM 1 (Track 1) — 🐱 Tuxedo

Euclidean rhythm generator — mathematically distributes beats evenly:

  • Steps — Pattern length (4-32)
  • Fills — Number of hits spread across steps
  • Rotate — Shifts pattern start point
  • Swing — Delays offbeats for groove feel

🎵 DRUM 2 (Track 2) — 🐱 Black Cat

Second rhythm layer with Mode Switch:

  • PERC mode — Percussion sounds (clicks, tones)
  • BELL mode — Melodic bell tones for harmonic rhythm

Use Polyrhythm presets (3:4, 4:5, etc.) to set complementary step counts between both drums for interlocking patterns.

🎚️ MIXER

  • Volume/Reverb/Delay — Drag faders up/down
  • Filter — Tap label to cycle type (LP/HP/BP), drag for cutoff
  • Chorus — Stereo width and shimmer on effects
  • Duck — Drums reduce other tracks (sidechain pumping)

⌨️ KEYBOARD

1-4 toggle tracks • Space toggle selected • A play all • R randomize • S song mode • Esc stop all • Arrows navigate/adjust
